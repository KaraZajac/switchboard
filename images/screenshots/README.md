# Screenshots

Taken 2026-09-13 from the 2.3.0-beta build, on a real network
(irc.netslum.io, `#switchboard-test`) with a staged conversation. Desktop
shots are 1440×900, phone shots 1080×2400 from an emulator. All are safe to
use on the website and in the README.

| File | What it shows |
| --- | --- |
| `hero.png` | Desktop and phone side by side on the same conversation |
| `desktop-chat.png` | A channel on the desktop: inline picture, a GIF, emoji, the member list |
| `desktop-mention.png` | Typing `@` offers everyone in the channel |
| `desktop-emoji-names.png` | Typing `:sm` offers emoji by name |
| `desktop-emoji-picker.png` | The emoji picker, searchable by name |
| `desktop-gifs.png` | The GIF picker (Klipy): GIFs, stickers, clips, memes |
| `desktop-add-network.png` | Adding a network from the curated list |
| `desktop-certificate.png` | A self-signed certificate offered for trust, fingerprint and all |
| `desktop-settings-appearance.png` | Themes, compact mode, font size, time format |
| `desktop-settings-behaviour.png` | Auto-away, rejoin after kick, join/part lines, plain-text logs |
| `phone-chat.png` | The same channel on the phone, pictures and GIFs inline |
| `phone-drawer.png` | Networks and channels in the drawer |
| `phone-members.png` | The member list with operators first |
| `phone-mention.png` | `@` completion above the keyboard |
| `phone-emoji-names.png` | `:sm` emoji completion above the keyboard |
| `phone-gifs.png` | The GIF picker sheet |
| `phone-settings.png` | Settings, with the themes shared with the desktop |
